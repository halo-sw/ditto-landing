# Ditto 홈 V11 — 레퍼런스 구도 적용

2026-11-12. 현재 홈 화면은 V11이 기준이다. V10의 좌우 분할 히어로와 설명 패널 구성을 교체했다. 실제 앱의 서체·색·위젯·관계 규칙은 유지한다.

## 화면에서 달라진 부분

| 구간 | V10 | V11 |
|---|---|---|
| 첫 화면 | 왼쪽 대형 광고 문구, 오른쪽 회전한 플래터 | 화면을 가로지르는 서로 다른 다섯 위젯, 중앙 주인공, 아래 짧은 중앙 선언 |
| 내비게이션 | 떠 있는 둥근 알약 형태 | 상단 전폭의 얇은 바, 현재 장의 밑줄 |

| 디토 | 두 패널 안의 설명과 위젯 | 중앙 제목 하나와 열린 원본·사본 이동 무대. 경로가 큰 그래픽에 연결 |

| 아날로그 | 다섯 개 작은 상자 | 큰 비율별 이미지 필드와 세로 목차 |

## 참고한 실제 구도

Skeep 홈의 그래픽 띠 → 중앙 선언 → 짧은 본문 → 작은 CTA 순서를 적용했다. 1440px 원본에서 그래픽 띠는 약 y92–450, 제목은 y606에 있다. 주인공과 보조 이미지의 크기 차이가 확실하며 양끝은 화면 밖으로 이어진다. Ditto는 해당 이미지 자리에 실제 음악·사진 필드·상태·To-do·방명록 위젯을 사용한다.

Negotiation의 큰 설명 장면처럼 디토는 한 무대에서 원본과 수신 공간을 보여 준다. service2의 문자를 시각 재료로 쓰는 방식은 기존 ASCII 주파수에 유지한다. Skeep의 폰트·사진·로고를 가져오지 않는다.

참고: https://skeep.site/pages/index.html / https://skeep.site/negotiation/ / https://skeep.site/service2/

## 동작과 콘텐츠

- 히어로: 다섯 실제 위젯이 위치와 크기를 이어 바꾼다. 모든 조합이 지정된 높이 안에 들어오며 키보드 버튼과 모션 줄이기를 지원한다.
- 플래터: 이미지뿐 아니라 음악·To-do·포스트·D-Day·상태·텍스트·방명록·영상으로 배치 자유도를 보여 준다. 앱의 8칸 격자를 유지한다. 원본 데모 데이터는 수정하지 않고 랜딩 전용 데이터를 준비한다.
- 디토: 소라 원본 → 지우 사본 → 그룹에 공유된 소라 원본 → 하은 사본. 출처, 최대3개, 3초 홀드와 취소, 재디토 불가를 유지한다.
- 긴 디토 소개는 중복 큰 제목과 분리해 규칙 펼침 안에 보존했다.
- 이미지 필드는 빈 상태로 구성했다. 더미 사진과 가짜 앱 캡처는 넣지 않는다. 실제 위젯 UI는 코드로 렌더링한다.
- 카메라·이름·아이디·사진 카드 저장과 기존 코드 발급 흐름을 유지한다.

## 파일과 로딩 순서

- `assets/v11/landing.css/js`: 새 전체 구도, 히어로, 세 플래터 무대, 장별 리듬, 내비게이션.
- `assets/v11/prepare.js`: 랜딩 플래터에 다양한 위젯 콘텐츠를 준비. v9 prepare 다음, v8 home 이전에 실행.
- `assets/v11/ditto.css/js`: 새 열린 디토 무대. **v9 ditto.js와 함께 로드하지 않는다.**
- `assets/v11/life.css/js`: 앱·아날로그 목차와 공유 이미지 영역.
- v8 실제 위젯·격자 엔진, v9 home(갤러리·사진카드), v9 frequency는 계속 사용한다.
- v9 refinement.js는 V11에서 로드하지 않는다. 장면 색상과 히어로는 landing.js가 담당한다.
- 글꼴 생성 스크립트는 v11 JS 문구도 포함한다.
