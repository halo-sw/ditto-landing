## 고정 규칙 (모든 단계에 적용)

- 목표는 "최대한 깔끔하게 다듬기". 정지 시안을 새로 그리는 일을 반복하지 말고 **실제 페이지(index.html)를 직접 고친다.**
- **관계 지도(relationship ontology)와 초대장 출력은 반드시 남긴다.**
- **iF 어워드 제출본(덱 01~08)의 내용은 모두 페이지에 있어야 한다.** 겉모습만이 아니라 장별 내용까지 대조한다.
- 주 버튼은 App Store. 대표 문장은 "우리로부터 시작되는 작은 공간."
- 서체는 Pretendard 하나 (덱의 PP Rounded는 파일이 없는 유료 서체).
- 메뉴는 원래처럼 떠 있는 알약 모양(floating UI).
- 3D 카메라·아이폰 모양을 어필하지 말고 **앱의 실제 UI 화면**을 보여 준다.
- 디토 실제 디자인 토큰·실제 에셋만 쓴다. 문구는 앱 UX Writing 가이드(해요체, "친구 신청", "됐어요")를 따른다.
- 커밋·푸시·배포는 사용자가 요청할 때만 한다.

### 7. 최종 검수 + 카메라 구간 복원 + 중복 (v5 3차, 11-10)

> 디자인 최종적으로 검수해서 업데이트 해줄래? 그리고 지금 if 어워드 제출본에 있던 다양한 카메라 섹션이 빠져있고, 중복되는게 있어서 한번 확인하고 수정해줫으면 좋겠어.

반영:
- 아날로그 구간을 덱 06장 기준으로 복원: 사진 부스·캠코더·무전기·편지 오브제 카드 + 방명록 카드 (덱 제목이 '다섯 가지'인데 카드가 4장이라 추가).
- 촬영 과정: 사진 부스 네 컷 → 함께 쓰는 카메라(12·24·36장) → 아침 7시 공개, 그리고 만나기 → 함께 찍기 → 플래터에 간직하기 → 다시 만나기.
- 중복 정리: 6단계 "Ditto = 나도" 구간 삭제(살펴보기·가져오기·퍼뜨리기는 디토 구간 아래로), 관계 지도 위 옛 제목 삭제, "남에게 잘 보이기보다 나답게" 중복 제거, 친구 구간 소개글 축소, 앱 화면이 반복되던 아날로그 카드를 덱 그림으로 교체.
- 순서: 왜 → 습관 전환 → 세 가지 생각 → 플래터 → 위젯 → 디토(= 나도) → 친구(주파수·관계 지도) → 사회적 영향 → 아날로그 → 주요 기능 → FAQ → 초대장.
- "눌러봐!" → "눌러 보세요.", 주요 기능에 "함께 찍은 필름" 추가.

### 18. 다운로드 버튼 · 움직이는 세 단어 설명기 · 설치 구간 (11-10, 클라우드 세션)

### 19. 한 호흡 구성 · 플래터의 칸 · 위젯 모음집 · 디토→주파수 과정 · 관계 지도 읽는 법 (11-10, 클라우드 세션)

> "2,3으로 작업해주되 … 매력적이라고 판단되는 에셋들을 적용해서 웹사이트를 구성 / 플래터 그리드에 대한 설명 / 디토 프로세스, 주파수로 이어지는 설명 / 관계 지도에 대한 디테일 업데이트 / 위젯 (AI Slop) 느낌 안 나는 감각적이고 귀여운 위젯의 모음집 강조형"
> "위젯 자체가 지금 다 누끼가 따져있는데, 뒷 배경이 잘리지 않게 업데이트 해줘." (피그마 UI_Final 링크)

| 지시 | 반영 |
|---|---|
| 첫 화면 → 설명기 한 호흡 | 사이에 끼어 있던 사진 구간을 "만든 이유" 바로 앞으로 옮김. 첫 화면 다음이 곧바로 선언 + 움직이는 세 단어 설명기 |
| 플래터 그리드 설명 | 새 구간 `#grid` "칸마다, 요즘의 내가 놓여요.": 여덟 칸짜리 판 위에 실제 위젯 11개가 흩어져 있다가 칸에 맞춰 내려앉음. 크기 칩(2×2 · 4×2 · 3×4 · 4×3 · 6×4)을 누르면 그 크기의 위젯만 비춤(가만두면 차례로 넘어감). 칸 수와 크기는 피그마 "신규 위젯" 페이지의 `11 sizes / actual grid`(2×2=86.5pt, 4×2=181×86.5pt …)와 페이지 속 플래터 화면 좌표에서 확인 |
| 디토 과정 → 주파수 | v5에서 숨겼던 **디토 네 단계 카드**(빛나는 사진 → 꾹 눌러 가져오기 → 출처가 남아요 → 내 방 한쪽에)를 디토 구간으로 되살리고, 구간 끝에 "디토가 오가면, 둘 사이에 주파수가 생겨요."로 이음. 숨겼던 **친구가 되는 다섯 걸음**은 주파수 구간(21일 연출 아래)으로 옮겨 되살림 |
| 관계 지도 디테일 | 지도 위에 제목("가까워진 과정이, 한 장의 지도가 돼요."), 아래에 읽는 법 네 칸(가운데는 나 / 안쪽은 친구 / 바깥은 친구의 친구 / 구슬은 교류 한 번, 여섯 색) |
| 위젯 모음집 | 위젯 구간을 어두운 진열대로 바꾸고, 돌려 보던 띠 대신 **위젯 추가 화면의 15종 그리드를 통째로** 보여 줌(갈래 탭, 누르면 실제 모습과 설명). 띠(`.wsp`)는 숨김 |
| 위젯 배경이 잘리지 않게 | 피그마 UI_Final의 위젯 추가 카드(`Cards/ScrollContent` 3001:25915)에서 14종을 3배(537px)로 다시 내보내 `assets/wa-*.webp` 교체. 이전 것은 320px였고 이미지 위젯은 튀어나온 사진 윗부분이 잘려 있었음. 기분(Mood)은 이 카드 묶음에 없어 기존 파일 유지 |

`#concept` 구간은 18번에서 없어졌고, 영상(13번)은 14번에서 뺐으므로 관련 주의는 해당 없음. 서체 서브셋 다시 만듦.
