# Ditto 홈 — 간격·서사·그래픽 재구성

2026-11-12. V9 구현에 이어 적용한 현재 홈 화면 기준이다. 실제 위젯과 앱의 관계 규칙은 유지하고, 설명보다 핵심 장면이 먼저 읽히도록 구성했다. 점수로 완성도를 단정하지 않는다.

## 페이지 순서

1. 히어로: 큰 브랜드 문장과 실제 위젯 구성. 3열의 조각들이 자유로운 위치로 들어오며, 배치 버튼으로 바꾼다.
2. 짧은 서비스 소개와 플래터·디토·주파수 진행선.
3. 플래터: 자유 배치를 기본으로 보여 준다. 3열 격자 비교, 세 배치, 직접 이동·크기 변경. 모바일은 체험 보드를 상세 설명보다 앞에 둔다.
4. 위젯 14종: 같은 위젯의 크기가 연속적으로 바뀐다. 치수와 모서리 조작점으로 크기 변경을 보여 준다.
5. 디토: 소라 원본 → 지우의 사본 → 그룹에 공유된 소라 원본 → 하은의 사본. 원작자 칩이 이동하는 사본에 붙어 있다. 단계 선택은 큰 장면 아래에 둔다.
6. 주파수: 하은과 소라의 두 ASCII 리본에 양방향 교류가 흐르고, 기존 글자들이 중앙의 디토 심볼로 모인다. 신청 버튼 → 애칭·편지 → 수락. 수락 후 한 번의 연결 효과.
7. 주파수의 의미, 관계 철학, 앱 소개, 6개월 관계 지도, 아날로그, 카메라·초대장.

## 간격과 반응형 규칙

- `.wrap`은 폭만으로 여백을 정한다. 이전 inline padding을 명시적으로 제거했다.
- 1440px: 실제 콘텐츠 x96, 폭1248. 390px: x20, 폭350. 768px: x32, 폭704.
- 섹션 간격112px, 모바일72px. 제목과 콘텐츠 간격48px, 모바일32px.
- 플래터 장면 시작은 데스크톱 약2600px에서1575px로 앞당겼다.
- V8의 flex·grid·order 잔존 규칙을 명시적으로 정리했다. 모바일 플래터 설명, 주파수 상세, 카메라 필터의 세로 글자 문제를 수정했다.
- 태블릿 아날로그는3열, 모바일2열. 모바일 디토는 전체 폭의 설명과 세로 장면으로 구성한다.

## 이미지 필드

더미 사진·임의 앱 캡처는 추가하지 않았다. 실제 위젯 이미지 영역은 크롭 코너로 비워 둔다. 앱 소개의 피드는 겹친 면, 대화는 연결되는 두 면, 카메라는 네 컷의 빈 프레임으로 구분했다. `data-media-slot` 식별자는 유지했다. 이 프레임은 앱 화면을 가장한 UI가 아니다.

## 구현 파일

- `assets/v9/refinement.css`: 컨테이너, 간격, 헤드카피 위계, 미디어 프레임, 반응형 및 이전 스타일 충돌 정리.
- `assets/v9/refinement.js`: 실제 카드의 등장, 필드 프레임, 현재 장면에 따른 내비게이션 색상.
- `assets/v9/home.js`: 실제 위젯 노드 유지·크기 변형, 치수 프레임, 모서리 크기 전환, 화면 폭에 맞는 스케일.
- `assets/v8/home.js`: 플래터 기본 상태, transform 기반 격자 전환.
- `assets/v9/ditto.js/css`: 실제 공유 요소 이동과 출처, 큰 원본·수신 보드 중심 구성.
- `assets/v9/frequency.js/css`: 연속 ASCII 리본·교류 펄스·심볼 수렴·신청 전후 상태.
- `index.html`: 소개 순서, 간결한 헤드카피, 긴 관계 설명 재배치. 초대장 통계의 잘못된 응답은 NaN 대신 대시를 표시한다.

## 검증

- Chromium 1440·768·390·375px: 가로 넘침0, JavaScript 오류0.
- 위젯14종의 첫/마지막 크기, 모서리 크기 버튼, 빠른 연속 선택, 세 배치, 격자 왕복, 키보드 크기 변경 통과.
- 디토: 3초 홀드·조기 취소·키보드·빠른 단계 전환·그룹 원본 수신·숨겨진 포커스·자동 스크롤 이동 없음 확인.
- 주파수: 네 단계·방향키·신청/수락/초기화·좁은 화면 폼·다크 내비게이션 확인.
- 모션 줄이기 환경에서도 같은 내용을 정지 상태와 직접 조작으로 확인.
- 모바일 사진 입력 → 필터 → 이름/아이디 → 실제 PNG 다운로드 확인. 초대장 발급 서버에 실제 쓰기를 수행하지 않았다.
- 실제 iPhone Safari 및 실제 카메라 하드웨어 검사는 포함하지 않는다.
