# 홈 v8 명세 (2026-11-12)

홈(`index.html`) 한 장을 소개 문안 7구간 순서로 다시 짰다. 하위 5쪽(`/platter/ /ditto/ /frequency/ /play/ /story/`)은 이번에 손대지 않았다.

- 스타일 `assets/v8/home.css` · 동작 `assets/v8/home.js`
- 실제 위젯·격자 `assets/v8/platter.css` `platter-grid.css` `platter-render.js` `platter-grid.js` `platter.js` `platters.js`
- 실제 앱 화면 `assets/v8/shots/*.webp` (11-11 공모전 제출 원본에서 가져옴)
- 문구를 바꾸면 `python3 scripts/landing_font.py <PretendardVariable.ttf>` 로 글꼴 서브셋을 다시 만든다 (`assets/v8/*.js` 도 읽는다).

## 3. 플래터 장면

- 판은 앱 격자 규칙 그대로다. 가로 8칸, 2×2부터 6×8까지 칸 단위, 옮기면 밀어내거나 같은 크기끼리 자리를 바꾼다 (`platter-grid.js` = `GridEngine.swift` 이식).
- 처음에는 '3줄 격자'(사진 여섯 장이 같은 정사각형)로 보이다가, 화면에 들어오면 각 사진이 제 위젯 자리로 날아가고 메모·상태·방명록이 뒤따라 켜진다.
- '다르게 놓아 보기'는 같은 위젯 10개를 세 가지 배치로 돌린다. 배치는 `home.js` 의 `LAY`. 모두 16줄 안.
- 진열대는 앱 추가 시트 기준 14종(`DittoWidgets.catalog`). 이름·설명은 앱 문구 그대로. 카드를 누르면 6×4 이하의 다음 크기로 바뀐다.

## 4. 주파수 장면

- 글자 칸(데스크톱 12×19, 모바일 9×15) 위에 두 신호를 `d i t t o !` 글자로 그린다. 위 = 하은, 아래 = 소라.
- 스크롤이 21일이다. 내려갈수록 두 신호의 높이·박자·간격이 맞아 가고, 맞닿는 자리에 흰 글자가 켜진다.
- 단계와 색은 앱 `FreqStage` 그대로: 잔잔 `#8E919E` · 선명 `#2BC4A8` · 곧 열림 `#5A5BF2` · 열림 `#AA4AF4` → `#FA97E2`.
- 끝에서 두 신호가 한 줄로 겹치고, 글자 타일이 디토 마크(d · 하트 · 점) 모양으로 켜진다. 옆에 애칭 · 편지 · "이제 서로 친구예요" 카드.
- 왼쪽 위 기록 여섯 줄은 앱이 보는 신호(디토 · 그룹 대화 · 함께 단 댓글 · 리액션 · 만남)다. 점수는 어디에도 적지 않는다.

## 5. 카메라 → 초대장

1. 카메라 켜기(또는 사진 고르기) → 색감 다섯 가지 → 찍기. 색감 값은 앱 `camera-looks` 프로필(토스 27 · VHS 캠 · 픽셀 팔 · 아날로그 포토부스 · 클램셸 05)을 옮겼다.
2. '이 사진으로 초대장 만들기' → 사진이 초대장 왼쪽 면에 들어간다 (`#tkPh`, 저장 이미지에도 그려진다).
3. 이름·아이디 → 초대장 뽑기 → 이메일을 남기면 번호와 코드가 발급된다 (기존 서버 함수 그대로).

사진은 브라우저 밖으로 나가지 않는다. 서버는 건드리지 않았다.

## 6. 확인이 필요한 것

- **코드 발급에는 지금도 이메일이 필요하다.** 서버 함수 `claim_launch_ticket` 이 이메일과 동의를 요구하고 이메일당 한 장만 준다. 이름·아이디만으로 코드를 주려면 서버 함수를 바꿔야 한다.
- **색감 카메라 33종과 같이 찍기는 TestFlight 빌드에서만 열린다** (`CameraLookAccess.open`). App Store 0.1 사용자가 쓰는 필터는 사진 편집기 8종이다. ⑦의 "실제 앱에서 사용해 볼 수 있는"은 문안대로 두었다.
- 관계 지도 옆 제목은 "친구 30명"인데 지도는 채원 32명, 시우 28명으로 끝난다. 앱의 친구 한도는 15명이다.
- 하위 5쪽은 이전 내용 그대로다. 단계 이름(고요함 → 잔잔 등)과 장면이 홈과 다르다.
- 참고 사이트 6곳 분석은 사용량 한도로 끝내지 못했다.
