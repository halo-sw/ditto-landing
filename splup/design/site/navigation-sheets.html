01. 버튼 수 3단계, 배치 4가지

상태바는 OS 영역 · 콘텐츠 바는 최소 56pt

N0 / N1-L / N1-R / N2가 기본형입니다. 아래 N2 예시 세 개는 같은 구조이며 버튼과 중앙 콘텐츠만 바뀝니다.
비활성 버튼은 개수에 포함합니다. 로고·장식·그래버는 제외합니다. 버튼이 없어도 양쪽 64pt 공간을 유지해 제목이 중앙에서 움직이지 않습니다.

02. 시트는 같은 프레임

공통 헤더 · 공통 표면 · 목적에 따른 본문

편집 시트에는 작동하지 않는 그래버를 넣지 않습니다. 하단에 ‘완료’가 있으면 상단 저장은 생략합니다. 확인 시트의 닫기·배경 탭은 항상 취소로 처리합니다.

04. 화면이 늘어나도 지킬 기준

제목의 중앙은 흔들리지 않게

양쪽 슬롯을 같은 폭으로 예약합니다. 큰 글씨는 줄바꿈과 높이 확장을 허용하고, 제목과 버튼을 겹치지 않습니다.

색은 역할에서 가져오기

헤더와 본문은 같은 modal 표면. 닫기는 중립색, 일반 저장은 브랜드색, 파괴적 액션은 위험 의미색을 사용합니다.

닫기와 저장을 분리하기

선택·조회는 닫기와 헤더 드래그. 편집은 취소와 저장. 변경사항이 있을 때만 폐기를 확인합니다.

시스템이 맡는 영역은 한 번만

상태바·safe area·시스템 시트 그래버를 중복으로 그리지 않습니다. 본문은 스크롤하고 주요 액션은 접근 가능한 위치에 유지합니다.

05. 시트보다 먼저, 작업을 구분해요

디자인 시스템의 선택 기준 · 화면 전환 이관 전

작업 / 영역우선 형식이유

스티커 보드전체 화면 캔버스드래그·사진·그리기가 중심 작업입니다. 현재 즉시 반영 방식은 유지합니다.
