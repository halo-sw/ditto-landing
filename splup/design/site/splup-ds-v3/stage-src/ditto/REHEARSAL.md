# REHEARSAL — 디토하기 시연 (2026-11-15)

## 베낀 기준 예시

`examples/phone-touch` (Phone app: 카드가 화면으로 열리고, 닫히며 제자리로 접힌다). 무대 크기(400 × 520, 좁은 폭 358 × 520), 폰의 자리와 아래쪽 흘림, 카드 → 화면 열림(`Expand`), 누름 반응, 대본의 박자를 그대로 두었다.

## 바꾼 것

- 내용: 운동 앱 → 디토. 목록은 소라의 플래터(프로필 핸들 + 위젯 타일), 고른 카드는 사진 위젯 "간식 부자", 상세의 버튼은 디토하기 버튼.
- 동작: 시작/일시정지 두 번 누르기 → 3초 동안 누르고 있기(`drag`를 거의 제자리에서 3초). 버튼은 한쪽으로 차오르지 않고 재질 전체가 짙어진다(실제 버튼의 규칙). 끝나면 "가져오는 중…" → "내 플래터에 담았어요"(분홍).
- 모양: Pretendard, 핸들 56 높이 · 모서리 16, 버튼 60 높이 · 모서리 12, 강조색 #AA4AF4. 무대 바탕은 투명(타일이 바탕).
- 실제 글자: 소라, @soramaybe, 간식 부자, 버튼 글자 네 가지. 나머지는 선과 도형.
- 가이드와 연결: 단계가 바뀌면 `splup-ditto-demo` 이벤트, 버튼 색은 `--splup-demo-a/b`.
- 포스터(모션 줄이기 · 정지 화면): 상세가 열려 있고 버튼이 "내 플래터에 담았어요"인 장면.
