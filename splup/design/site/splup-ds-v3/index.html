    Pretendard · 하나의 서체

    브랜드 설명과 사용자 콘텐츠 모두 Pretendard를 사용합니다. 위계는 크기·굵기·행간으로 구분하며, 로고는 원본 SVG 아트로 유지합니다.

    사용할 때 확인할 것

    • 글꼴을 나누는 기준 — LINE Seed Sans App: 워드마크·온보딩/스플래시 타이틀·빈 상태 브랜드 카피·발표/마케팅 지면의 라틴. Pretendard: UI 전 영역·사용자 생성 콘텐츠·국문 전체. 스타일(tN)은 공유하고 폰트만 보이스로 갈린다 — 예: 브랜드 Display = t14StaticBold+LINE Seed, 화면 타이틀 = screenTitle+Pretendard.
    • 한글이 있는 문장의 글꼴 — LINE Seed Sans App은 라틴 전용(한글 글리프 없음). iOS에서 자동 폴백이 시스템체로 떨어지므로, 국문 혼용 문자열은 코드에서 명시적으로 Pretendard를 지정한다. 한글 브랜드 표기가 꼭 필요한 예외 지점만 LINE Seed Sans KR(Th·Rg·Bd) 검토.
    • 크기를 고정하는 경우 — 브랜드 지면(온보딩·스플래시·공유 카드·발표)은 레이아웃 고정이므로 tNStatic*을 쓴다. 스크롤되는 UI 본문은 기기의 글자 크기 설정을 따르는 스타일.
    • 글꼴별 지원 굵기 — 3단(400/500/700) 중 LINE Seed Sans App은 Rg(400)·Bd(700)만 대응하고 Medium(500)이 없다(보유: Th·Rg·Bd·XBd·He). 브랜드 보이스에서 Medium 스타일 사용 금지 — 보드가 EN Display 24를 Regular로 지정한 것과 일치. 국문 Medium은 Pretendard 가변 wght 500으로 정상 지원.

    말투의 기준 5가지

    • ① 해요체, 청유형. 명령하지 않는다 — "작성하세요" 대신 "남겨보세요", 확인 질문은 "~할까요?". 브랜드 버벌("통하면 디토해!")을 제외하면 시스템 카피에 느낌표를 아낀다.
    • ② 재촉하지 않는다. 주파수는 조용히 익는 것 — 스트릭·D-Day 카운트다운·"놓친 소식 N건!" 류의 FOMO 어투 금지. 알림 기본값도 조용한 쪽(D-Day 알림 기본 없음).
    • ③ 숫자로 압박하지 않는다. 주파수 진행률·게이트 수치(21일)를 사용자에게 노출하지 않는다. 잠금 카피는 "곧 열려요"가 공통 원본. 상한(친구 15·디토 슬롯 3·위젯 10)은 도달했을 때만 알려준다.
    • ④ 행동을 수단화하지 않는다. 디토는 목적이지 수단이 아니다 — "친구가 되려면 더 디토하세요"처럼 행동을 보상의 조건으로 쓰는 문장 금지.
    • ⑤ 장난기는 브랜드 자리에서만. 위트는 브랜드 보이스(LINE Seed 지면·온보딩·빈 상태 첫 줄)까지. 확인·삭제·오류 등 사용자가 결정하는 순간의 카피는 서체처럼 뒤로 물러난다(글꼴을 나누는 기준와 동일 구조).

    앨범 선택에 따라 CD 커버와 본체 색이 함께 달라집니다. 사각 썸네일과 서비스 출처도 유지합니다.

    • Spotify: 커버와 출처를 표시하고 Spotify 링크로 이동합니다.
    • Apple Music: 앱 내 콘텐츠 링크는 서비스 아이콘과 전체 이름을 표시합니다. 마케팅용 공식 배지와 앱 내 출처 라벨은 구분합니다. 재생은 MusicKit 연결 후 제공합니다.
    • YouTube Music: 공유된 음악 링크로 이동합니다. YouTube Data API 응답을 전용 음악 재생 API로 표시하거나 숨겨진 오디오 재생으로 연결하지 않습니다.

    외부 서비스 배지

    높이 22px · 아이콘 14px · 글자 11px · 모서리 6px · 가장자리 여백 8px. 충분한 폭에서는 서비스명과 ↗를, 작은 카드에서는 아이콘과 ↗를 표시합니다. GIF는 파일 형식이므로 외부 이동 화살표와 구분합니다.

    음악 서비스는 22px 행 안에 서비스명과 ↗를 표시합니다. Spotify 아이콘은 최소 21px와 주변 11px 여백을 확보해요. 음악 재생형은 위젯을 눌러 재생·일시정지하고, 링크형은 위젯 전체를 눌러 서비스에서 엽니다. 링크형에는 재생 표시를 붙이지 않아요.

    배지는 도착 위치를 알려주는 표시입니다. 별도 작은 버튼으로 만들지 않고 위젯 전체를 눌러 이동합니다. 사진·GIF의 Ditto 배지는 우측 상단, 글자가 있는 위젯의 Ditto 배지는 출처 영역 우측에 배치합니다. 사진·영상의 서비스 배지는 우측 하단에 배치하고, 음악의 출처는 곡명·아티스트 아래에 정렬해요.

    글자와 긴 콘텐츠

    본문 14px / 행간 20px, 제목 14px, 보조 정보 11px를 유지합니다. 질문은 120자, 답변은 500자까지 입력할 수 있으며 카드에서는 질문 최대 3줄·답변 최대 6줄까지만 보이고 나머지는 말줄임합니다. 실제 앱에서는 전체 내용을 상세 화면에서 보여주도록 설계합니다. 이 페이지는 말줄임을 확인하는 예시입니다.
