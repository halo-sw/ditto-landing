1. 전시 포스터

- 모두 정확한 A1 세로 594×841mm. 흰 테두리 디자인, 별도 도련 없음.
- 주문: A1 세로 2종 각 1장, 디지털 대형출력, 무광 지류 옵션 우선 상담, 코팅/박 등 추가 후가공 없음.
- 100% 실제 크기로 출력. 임의 맞춤 축소/확대 금지. 인쇄소 A1 용지 규격과 미리보기를 확인하세요.
- 설치: 두 장 사이 20mm, 전체 1,208×841mm. 윗선 바닥에서 2,340mm. 개인폭 1,800mm 중앙.
- 벽면은 제공 마스킹테이프 보양 후 양면테이프. 벽면 직접 양면테이프·시트지·못·와이어 금지.

2. A6 양면 엽서 50장
- ditto-postcard-A6.pdf: 1쪽 앞면, 2쪽 뒷면. 양면 출력 후 세로 방향을 맞춰 재단합니다.
- 주문/재단 크기 105×148mm. PDF 작업 크기 109×152mm, 사방 2mm 도련.
- TrimBox는 정확한 재단선, BleedBox는 작업 크기입니다. 페이지에 재단선 인쇄 표시는 없습니다.
- 일반 카드 상품, 아트지 250g 내외 우선 견적, 재고와 단납기 가능 종이 최종 확인. 코팅·오시·박 없음.
- 업체 자동 맞춤을 사용하면 크기/도련이 달라질 수 있으니 작업 크기를 유지하고 미리보기를 확인하세요.

3. 50mm 정사각형 배포용 스티커
- ditto-sticker-50mm.pdf: 1종 디자인. 50개 배포, 최소 주문 단위가 더 크면 50개 이상 발주.
- 주문/반칼 크기 50×50mm. PDF 작업 크기 54×54mm, 사방 2mm 도련.
- 사각반칼 규격 선택 상품용 아트워크입니다. 별도 커팅 레이어/커스텀 칼선은 포함하지 않았습니다.
- 규격 칼선/편집기를 제공하는 상품에서 50×50mm를 지정해 검수하세요. PDF 내 칼선 제출 옵션이라면 인쇄소 템플릿 작업이 추가로 필요합니다.
- 단납기 조건은 묶음재단, 추가 코팅 없음. 배포할 때 배경지를 낱개로 나누는 작업이 필요할 수 있습니다.
- 벽면 부착용이 아니라 관람객 배포용입니다.

4. A5 QR 안내
- ditto-qr-sign-A5.pdf: 148×210mm, 단면 1장. A5 세로 안내꽂이에 넣습니다.

공통 인쇄 확인
- 글꼴은 PDF에 포함되어 있습니다. 로고와 QR은 벡터입니다.
- 디지털 출력용 RGB PDF이며 PDF/X 또는 CMYK 변환 파일은 아닙니다. 인쇄소의 RGB 접수와 출력 프로파일을 확인하고, 변환 후 보라색/사진 인쇄색을 확인하세요.
- 포스터 사진은 현재 랜딩의 원본을 재사용했습니다. 확대 사진의 유효 해상도는 약 130~160ppi 수준이므로 먼저 부분 샘플을 확인하세요. 앱 화면은 1320×2868px 원본을 사용했습니다.
- 화요일 주문→목요일 도착을 확정한 문서가 아닙니다. 결제 화면의 실제 제작 완료일과 방문수령 가능 시간을 확인하세요.
